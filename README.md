# IMC Environment Companion Skill

This folder contains `$imc-environment-art-direction` for hunting/battle backgrounds, playable environments such as the Adventurer Office, scenery and maps. It retains IMC's PawPop 2 rendering direction and environment integration guidance.

The character companion remains in `D:/Godot Projects/IMC-Companion-Skill` under `$imc-art-direction`, covering portraits, sprites, character animation and monsters.

## Install for Codex

Place this folder at `%USERPROFILE%/.codex/skills/imc-environment-art-direction`, or create a directory junction there pointing to this folder. Keep `SKILL.md`, `agents/`, `references/` and `references/media/` together. Each companion contains its own required references.

On the author's machine the environment source is `D:/Godot Projects/IMC-Companion-Skill-Environment`. A clone or copy on another machine needs its own installation at the Codex skills path.
